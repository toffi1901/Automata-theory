# SMC, regex 

На базе конечного автомата разработан распознаватель корректности вводимых строк, удовлетворяющих следующему шаблону
*\\имя_сервера\имя_ресурса\путь\*

имя_сервера – обязательное поле, строка литералов {[A-Z], [0-9]} в верхнем регистре длиной до 15 символов; 

имя_ресурса – обязательное поле, строка литералов {[a-z], [0-9], $} в любом регистре длиной до 32 символов;

путь – необязательное поле, представляет собой последовательность полей имя_каталога, разделенных символом ‘\’;

имя_каталога – необязательное поле, представляет собой строки литералов {[a-z], [0-9]} в любом из регистров длиной до 32 символов;


Длина строки не превышает 100 символов
